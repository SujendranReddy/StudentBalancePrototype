# Student Balance Prototype

This project is a high-fidelity prototype of the Student Balance application created using ASP.NET Core MVC in Visual Studio.

## How to View the Prototype

1. Open the project in Visual Studio.
2. Run the application.
3. When the website opens in the browser, right-click anywhere on the page and select **Inspect**.
4. Click the phone/tablet icon to enable mobile view.
5. Choose any phone device from the device dropdown, such as **iPhone** or **Pixel**.
6. Refresh the page if needed.

The prototype is designed to be viewed in mobile screen size, as it represents a mobile application interface.
